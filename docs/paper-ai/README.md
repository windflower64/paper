# Paper AI handoff

This folder provides a self-contained Chinese research handoff for AI-assisted paper writing. Start with [Research_Handoff_Public_ZH.md](Research_Handoff_Public_ZH.md).

The handoff records the current research framing, implementation facts, measured results, negative findings, and claim limits. Read its opening instructions first. It embeds the source knowledge documents so readers do not need access to the author's local Windows paths. Prior reviewer feedback is summarized; the original review text is kept private.

The code in this repository is the D-FINE implementation snapshot on which the handoff is based. The handoff includes local result paths as provenance; model weights, datasets, SAM mask caches, and generated predictions are intentionally not part of this share.

This repository is public. Do not add private data, credentials, unpublished reviewer identities, or artifacts that are not intended for public access.
