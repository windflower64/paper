# SAM 与 M 关系验证：旧证据审计及首组启动

日期：2026-09-27。性质：正在执行的研究记录，不是论文结论。

## 要检验的主张

既定主线是“以形状知识约束目标表征，以内容关联获取跨模态补充”。前一轮普通双模态融合对照支持继续研究 R2，但没有证明 SAM 与 R2 之间的关系。本阶段先回答一个最直接的问题：在同一个 M-OTE2 修正版本下，保留与关闭 SAM 形状指导，检测能力及小目标/严格定位指标如何变化？之后再看融合前后的目标—近背景表征，区分检测收益与结构保持机制。

## 已有证据为何不能直接拼成当前四格

2026-09-24 的 A0–A5 同协议贡献分离使用旧 M-SD2.2 半强度，不能把其 A2/A3/A5 与当前 R2 的指标混算。该实验中 SGC2 在旧 M 上较有一致正向趋势，SQER2 的独立及额外贡献不稳；A5 最佳 AP 较高，但同权重 SQER2 旁路几乎不改变 AP。它支持优先检查形状指导，却不足以宣称两个 SAM 环节必然协同。

更早的 `reports/156_sam_m_gain_retention/conclusion.json` 已对旧 C／CS／CM／CMS 做过四格缓存审计。末段 SAM 作用在 RGB-only 与旧 M 条件下均有一定正向 AP，但小目标表现及实例级收益没有构成稳定的“融合中结构保持”证据；其中所用 M、模型训练历史与当前 R2 不同。`20260918_RGB与SAM收益保留四组训练结果与下一步裁决.md` 还显示：成熟 RGB 中的 SAM 优势可以被固定保留，但当时新增 M 没有提供额外 AP 收益。负面历史应进入最终判断，不能只取新实验的有利轮次。

## 本轮首组：R2 保留、两项 SAM 指导关闭

对照从当前 R2 的同一公共初始化 `outputs/M_LAYOUT_RECOVERY_20E_TESTDEV/common_init.pth` 开始；仍使用同一核实后的 IR 源、同一 C 底座与 M-OTE2 修正布局、seed 0、物理 batch 8／累计 4、2 轮预热＋18 轮主训练、原 testdev 1820 图。设置 `sgc_enabled=False`、`sgc_aux_weight=0`，SQER2 结构仍构造在模型中但始终旁路，`sqer_shape_weight=0`。训练期仍可读取相同样本与 SAM 文件，但这两项损失不会进入优化。保留 SQER2 的构造与优化器参数配置，是为了尽量保持随机初始化和训练协议；旁路参数不会形成 SAM 检测作用。

不能从已训练两轮 SAM 的 R2 warmup checkpoint 分叉，否则无 SAM 组已经接受了 SGC2 监督。本组独立从共同初始化跑完整两轮预热，再继续至总计 20 轮。

真实批次预检已通过：前两个 batch 的 image ID 与样本张量 SHA256 均与原 R2 一致；两次 scratch 优化中 SAM 损失不存在，M 支路检测梯度非零，损失与预测有限，scratch 不保存正式权重。报告为 `reports/M_R2_SAM_FACTORIAL_20E_TESTDEV/no_s_preflight.json`。

2026-09-27 07:10（北京时间）启动本地持久队列，目前已进入预热训练。配置 `D-FINE/experiments/phase_m/m_r2_no_s_warmup.yml`、`m_r2_no_s_main.yml`；队列脚本 `D-FINE/tools/queue_m_r2_no_s.py`，状态 `reports/M_R2_SAM_FACTORIAL_20E_TESTDEV/queue_status.json`。日志分别位于 `outputs/M_R2_SAM_FACTORIAL_20E_TESTDEV/no_s_warmup/train_console.log` 与 `no_s_seed0/train_console.log`。队列会在预热成功且存在 `last.pth` 后自动进入主训练；失败则停止并登记状态，不继续下一阶段。

## 训练结束后的判读顺序

1. 核实阶段退出码、epoch 完整性与最佳 EMA；独立复评完整 12 项 COCO 指标。
2. 与当前含 SAM 的 R2 比较最佳点、对应轮次、末段曲线，特别关注 AP、APS、AP75 与 AR；同时记录参数量和实际 M 写入。
3. 复用两组最佳权重做逐图实例分析：小目标命中/丢失、近背景误检、候选排序及共同检出目标的框 IoU。最佳轮不同，逐图比较只作为探索，不冒充严格同轮因果。
4. 再做 S8 表征和 M 写入前后区域区分诊断，明确是否有证据支持“形状指导帮助融合时保持空间结构”。SAM 教师区域读数与独立检测结果需要分开解释。
5. 若“无 SAM＋R2”与含 SAM R2 接近或更好，先审视双环节必要性，不急于补完整四格或共享区域表征。若差异明确且与机制预测一致，再补真正缺失的 RGB-only 格子，计算条件性作用。

本轮结果只来自单种子、反复使用的开发集。SAM 与 M 的相互作用是否成立，不能用一次峰值差直接判定。
