# SBR2：可学习的局部定位特征

日期：2026-10-04。承接用户“继续尝试新模块的开发设计，有问题解决”的授权。已完成实现和预检，并启动两组对照队列，结果尚待训练验证。

## 1. 改进依据

SBR1两组最佳AP都约53.712，相比原模型53.680只高约0.032个百分点；SAM组没有优于GT-only组。其形状损失下降但检测定位未改善。候选覆盖、有效教师覆盖和修正范围没有显示主要阻塞。

一个明确的结构限制是：SBR1只能读取冻结的SQER局部特征，无法让这些特征适应定位。SBR2针对这个限制增加独立、可训练的S4/S8特征编码层。是否因此有效，须以本轮结果验证，不能把猜测当作已确认失败原因。

用通俗的话说：上一版让一个新学生拿着旧笔记修框；这一版允许学生重新整理局部图像信息，使它更适合判断框边的位置。

## 2. 结构与初始化

RGB S4/S8 backbone输出 → 新的可训练S4投影、S8投影和融合 → 每候选32×32局部采样 → 四方向交叉注意力 → 四边残差 → 精修框。

新局部编码的结构和初值复制旧SQER的对应层，但参数存储独立，绝不和旧分类支路共享可训练权重。开训前逐值核对初始融合图与旧SQER相同。读取器的其他参数直接使用SBR1共同初始化，因此与前一版相比，明确改变的是局部编码能否学习。

保持四个方向查询、两层注意力、空间坐标、45%独立四边残差范围。零初始化框输出便于复现原检测结果，没有额外弱门控。

旧RGB-T、C、M、SGC2、SQER2分类分支仍eval且冻结。准确描述应为“局部定位编码与框精修联合学习”，不是整套检测器或RGB backbone全量联合训练。

## 3. SAM的作用

离线SAM掩码形成四个方向的边界注意力目标，通过KL监督学生读取位置。GT框监督精修后坐标。因为局部编码现在可学习，两类损失均能改变定位分支的局部特征。

不改变教师筛选规则、不使用SAM掩码外接框替代GT，不在推理时读取教师。教师质量及形状/GT框规范不一致的问题仍然存在，本轮不同时改变所有因素。

## 4. 对照与训练

先R2_SAM，后R1_GT_ONLY，各30epoch，batch16。两组基座和新增参数初始化相同，采样顺序相同，唯一区别是新增形状KL权重0.05或0。

R1_GT_ONLY仍继承旧SAM相关能力，不能称为全系统无SAM。与SBR1相比，观察可训练局部编码是否有价值；SBR2内部R2−R1观察新增定位分支的SAM监督是否有价值。

保持seed0、3200训练/1820test-dev、512×640、无随机增强、AdamW lr1e-4、1epoch warmup后cosine、weight_decay1e-4、clip1。EMA更新率0.01；按最佳总AP检查点报告全指标。

基座和新分支全程FP32，不再使用此前失败的AMP训练路径。本轮协议显式保存precision和源码SHA，便于恢复和追踪。
