# Anti-UAV 现有模块效果盘点与证据边界

日期：2026-10-02。范围：当前准备写入论文的 C 底座、SAM 形状指导（SGC2＋SQER2）和修正后的 M-OTE2 R2；旧 A0—A5 作为独立历史对照。本文不是全部历史实验排行榜。

本轮重新读取 11 组原始训练日志、递归合并配置、计算最佳权重 SHA256，并与 5 份已有独立 EMA 复评报告逐项核对。没有新推理、新训练、改模型、改数据划分或推送 Git。这里的“核对复评”指本轮检查已保存的复评结果，不是本轮重新运行 GPU。

## 一、结论

**Anti-UAV 上确实已有支持 SAM 指导和目标证据融合的正向结果，不应因为 Tri-Modal 失败就推翻它们。** 当前协议中，完整 SAM 指导相对同 M、无 SAM 的训练对照，最佳 AP 提高 1.0569 个百分点，AP75 提高 3.0032 点，小目标 AP 提高 1.4897 点；十个有效 COCO 指标均提高。修正后的 M-R2 相对普通双模态全局融合，最佳 AP 提高 0.9033 点，小目标 AP 提高 1.6331 点；同权重关闭 M 或换成固定训练集平均红外证据也会掉分。

但不能概括成“每个模块、每个指标、每个数据集都有效”。SGC2 的正向训练证据较明确；SQER2 是小幅、非全面的分类证据修正；C 的最终 AP 增益较弱，且不是拟写的论文创新点。当前证据没有证明 SAM 恢复真实边缘，也没有证明它保证融合后的空间结构不受污染。

可以将 Anti-UAV 作为主要验证场景，冻结当前论文候选结构，减少围绕 Tri-Modal 的无目标补救。不能把其它数据集负结果省略后写成“多个公开数据集均更优”，也不能仅因 Tri-Modal 分数低就确定“只是数据集太难”。

## 二、统一评价口径

- Anti-UAV 当前使用 3,200 张训练图，原 test 的 1,820 张图作为开发验证（testdev）。原 test 已多次参与实验选型，不是未触碰的最终测试。
- 输入 512×640；本组物理 batch 8、梯度累积 4、AMP、seed 0；总 20 轮，其中当前 R2 系列为 2 轮预热＋18 轮主训练。
- **按每组最高 AP50:95 选择一个最佳 EMA，然后报告同一权重的其它指标**，不把各指标分别取峰值拼成一个模型。最后几轮均值只用于观察趋势，不替代最佳模型选型。
- 以下指标均为原始比例乘 100，差值是百分点。AP 指 COCO AP50:95，AP75 是 IoU=0.75，APS 是 COCO 小目标面积分组，不是输入短边小于 16 像素的分组。
- 本开发集没有可评估大目标，APL/ARL 原始值为 -1，本报告记为“—”，不记作零分。
- R2、R1、普通融合、R2 无 SAM、R2 仅 SGC2 的训练日志最佳向量均与已有独立复评 12 项逐值一致；本轮最佳权重哈希也与已有复评记录一致。
- 单 seed、单开发集。18 个相邻 epoch 不等于 18 次独立实验，不据此声称统计显著。

### 3.1 整套 SAM 指导：目前最有说服力的训练对照

完整 R2 与无 SAM 组均从同一公共初始化开始；RGB 来源为 COCO 兼容预训练参数，新任务部分按种子初始化，IR 来源为已核验的本项目红外预训练；不是全随机训练，也不是从历史成熟 A5 最佳检测权重续训。两组预热分别进行，无 SAM 组没有接受 SGC2 的预热监督。

完整 SAM－无 SAM，按未四舍五入原始数计算：

| 指标 | 增益（百分点） |
|---|---:|
| AP | +1.0569 |
| AP50 | +0.5362 |
| AP75 | +3.0032 |
| APS | +1.4897 |
| APM | +0.7747 |
| AR1 | +1.0112 |
| AR10 | +1.0231 |
| AR100 | +0.8930 |
| ARS | +1.9817 |
| ARM | +0.3752 |

最佳轮次两组均为 epoch16；18 个同轮 AP 比较中完整 SAM 高于无 SAM 16 轮，平均差 +0.9620 点，末五轮平均差 +1.3436 点。它不是单独一个偶然峰值的描述，但也不构成多次独立重复检验。

**可写：在当前 Anti-UAV 的 M-R2 检测配置中，SAM 形状指导训练方案改善检测，尤其 AP75 和小目标 AP。** 此对照同时改变 SGC2 监督和 SQER2 监督/读出，不能将全部 +1.0569 记给某一个环节。

### 3.2 SGC2：较强的分项证据

仅 SGC2－无 SAM：AP +0.7392、AP75 +3.3138、APS +0.2822、AR100 +1.4607。十个有效指标均正向。18 个同轮 AP 比较中领先 16 轮。

SGC2 是 RGB S8 的训练期分组约束，不是推理网络层；其形状掩码只在训练时使用。证据支持将它作为 SAM 形状指导的主要表征学习环节。无 SAM 与仅 SGC2 的预热监督不同，比较的是完整训练方案，不是同一权重临时开关。

### 3.3 SQER2：有作用，但主张必须准确

完整 SAM－仅 SGC2：AP +0.3177、APS +1.2075、APM +0.3918；同时 AP75 -0.3106、AR100 -0.5677、ARS -0.7890。18 个同轮 AP 比较中领先 11 轮，末五轮平均差 +0.4854 点。

这两组共用 R2 的两轮预热权重，主阶段主要变量为 SQER2 旁路和形状损失。各组最佳轮次仍不同，因此不能把最佳差全部当作单次读出算子的贡献。

完整 R2 同一最佳 EMA 推理时旁路 SQER2，AP 53.6804→53.5229，APS 47.8924→47.3643，AP75 58.0127→57.6232。正常－旁路分别 +0.1575、+0.5281、+0.3895 点。SQER2 的框坐标不改，变化来自分类分数/排序；AP75 增加不代表该支路直接修正了框。AR1、AR100、ARS 保持不变，AR10 反而下降 0.3548 点。

**可写：SQER2 提供小幅但可测的局部分类证据修正。不可写：它已全面提高定位和召回，或修复 S16 边缘。** 可与 SGC2 统一为一个 SAM 形状指导框架，但须公开两个不同作用点及分项消融。

### 3.4 M：设计对照和内容作用已有证据

完整 R2 相对普通双模态全局融合：AP +0.9033、AP75 +1.2159、APS +1.6331；18 个同轮 AP 中领先 16 轮。两者均有 RGB/IR 两条输入和完整 SAM 指导。

不过普通融合的 AR10、AR100、ARM 更高；R2 与普通融合还存在参数容量、作用层级、IR 目标性辅助监督及写入强度差异。该组支持 R2 **整套融合设计**，不能将 +0.9033 全部分配给其中某一注意力算子。

同权重检查：

| 完整 R2 最佳 EMA 模式 | AP | AP75 | APS | AR100 |
|---|---:|---:|---:|---:|
| 正常逐图红外 | 53.6804 | 58.0127 | 47.8924 | 67.8297 |
| 关闭 M 写入 | 52.7362 | 54.9321 | 42.7396 | 66.7652 |
| 固定训练集平均红外证据 | 52.9939 | 56.2924 | 45.6349 | 67.0964 |

正常－关闭 M：AP +0.9443、AP75 +3.0806、APS +5.1527、AR100 +1.0645；但 AP50 -0.1480、APM -0.5701。正常－固定平均 IR：AP +0.6865。说明当前权重确实使用了红外路径以及随图变化的内容，不只是固定偏置。

上述干预不等于从共同初始化独立训练“无 M”。旁路/平均证据会改变输入分布，掉分不能直接记作从头训练的净增益。当前协议尚缺严格的独立无 M 训练组；它是未来若主张“M 比没有红外必然更好”时的证据缺口，不是本轮新增训练任务。

R1 最佳 AP53.6134，R2 高 0.0670 点。R1 也有同权重关 M 掉分和正常逐图 IR 优于固定证据的结果，因此不能宣称只有 R2 能利用红外，或 R2 已压倒全部其它融合方案。

## 五、核心叙事能够说到哪里

可保留研究定位：**以形状知识约束目标表征，以内容关联获取跨模态补充。** 在 Anti-UAV 当前配置中，SAM 的训练指导帮助检测、M 读取逐图红外内容、RGB 作为输出框坐标参照，三个事实均有对应实现和不同强度的实验支持。

但“形状约束”目前描述的是训练机制，不等同于已经测得真实边缘保真。已有 GT 框内/邻近背景区域诊断显示 S8 特征差异明显改变，S16 前后没有一致保护优势，简单特征距离与小目标框改善近乎不相关。固定权重 M 干预的小目标正向响应，提供两者联系的线索，不建立 SAM→空间保护→M收益的完整因果链。

因此论文可以讲一个职责明确的框架，不应讲“证明SAM恢复了下采样真实轮廓，并彻底消除红外空间污染”。后者是超过现有证据的承诺，不是多拿一个 AP 就能解决。

## 六、如何处理其它数据集

Tri-Modal 的极小目标占比高，是已观察到的困难因素；实例级 SAM 修复增加了监督覆盖，但未把检测收益推广为一致正向。难度大能解释绝对 AP 低的一部分，**不能自动解释同数据集加 SAM/M 后的相对收益不成立**。还可能涉及标签空间、教师目标与检测目标差异、IR 特征适配和候选定位瓶颈，目前没有唯一根因。

如果优先完成一个主线清楚的论文，可采用：Anti-UAV 为主要消融和机制场景；UAV-CB/Tri-Modal 如实作为迁移/适用边界证据；保留当前结构，不因外部数据负结果立即全尺度加支路。摘要、引言中“多个公开数据集均有更好效果”的提前表述需等真正匹配的正结果后再使用。

本轮不执行上一轮规格中的“T8直接定位读取”结构/训练，也不删除它；当前用户要求是先盘点 Anti-UAV，而非批准扩大新实验。
