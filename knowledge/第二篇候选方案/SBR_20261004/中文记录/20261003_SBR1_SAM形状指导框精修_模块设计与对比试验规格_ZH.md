# SBR1：SAM 形状指导框精修——设计与执行规格

日期：2026-10-03。状态：设计完成，尚未实现、训练或验证。SBR1 是内部实验名，不代表已获得创新性或性能结论。

## 一、这次要解决什么

现有 SQER2 只修改类别 logit，不改变 D-FINE 已生成的框。当候选缺少准确定位时，评分排序不能创造更准确的框。本设计增加可训练的局部定位读取分支，让 SAM 轮廓监督通过学生的空间注意力参与最终四边修正。

不能把“只改分数”直接当作旧方法增益有限的已证实原因；也不能把 20261002 的训练集注意力检查当成定位改造一定有效的证据。本轮假设是：RGB 高分辨率局部特征仍含有可用于精修的几何证据，SAM 能帮助学生选取这些证据。

不重做 C、M、SGC2，不改变红外融合方式，不在线运行 SAM。保留旧 SQER2 分类修正以固定现有能力。新模块与 SQER2 共用 RGB 融合特征图，但不强制共用三个角色向量：内部/边界/背景是判别角色，左/上/右/下是定位角色，两者不同。

## 二、结构选择

选择“带坐标的四边注意力读取＋有界框残差”。不采用以下首轮路线：

- 从三个旧区域向量直接回归四个数：已有空间位置压缩，不能解决设计动机。
- SAM 掩码外接框直接替换检测框：推理无法使用 GT 提示，且掩码不等于检测标注规范。
- 另做完整分割解码器再转框：监督与部署链路变化太多，暂不需要。
- 改 D-FINE 内部所有解码层及分布回归：首轮难以区分贡献，保留后续可能性。

新模块使用两层交叉注意力、空间位置编码、四个方向角色、区域视觉证据和坐标统计。复杂度来自定位需求，不以层数作为创新证据。

## 三、输入、模块与 shape

以下忽略 batch，输入512×640、候选总数300、K=64、通道64。实现必须支持动态输入尺寸和 K=min(64,Q)。

| 步骤 | 输入与操作 | 输出 |
|---|---|---|
| 原检测路径 | RGB-T D-FINE；保留旧 SQER2 分类修正 | 原框300×4、decoder query300×128、最终类别logit300×1 |
| 候选选择 | 用旧 SQER2 之前的 base logit 选 top64；选择索引停止梯度 | 64个索引 |
| 共用特征 | 复用现有 S4/S8 投影及融合图，不改变旧路径数值 | 64×128×160 |
| 定位 ROI | 原框中心不变，宽高扩大2倍，最小32输入像素；裁到图像范围 | 每候选独立的采样网格 |
| 采样 | bilinear grid_sample，align_corners=False；定位专用32×32网格 | 64候选×1024位置×64通道 |
| 位置编码 | ROI内坐标(u,v)及(u²,v²)，Linear4→64，加到局部memory | 同上 |
| 四边查询 | LN+Linear128→64，分别加四个可学习方向向量 | 64候选×4方向×64 |
| 两层交叉注意力 | 每层4头，残差，LN，FFN64→128→64；第二层Q来自第一层，K/V来自同一局部memory | 更新查询64×4×64；末层平均头权重64×4×1024 |
| 定位证据 | 末层权重加权汇总未加位置编码的局部视觉memory；同时计算坐标均值及方差 | 每边64维视觉＋4维坐标统计 |
| 边回归头 | 拼接视觉64＋最终更新query64＋坐标统计4＋原框ROI坐标4＝136；共享LN/MLP136→128→64→1 | 每候选四边原始残差，64×4 |
| 框更新 | tanh限幅后加到原框四条边；scatter回300框 | 精修框300×4 |

四个方向顺序固定 L,T,R,B。batch实现可将B×K折叠，不能把64个候选混成一组。三个旧角色保留在旧SQER2；新四边角色独立参数。

最终更新query也进入框头，避免旧SQER2 evidence-only路径中末层更新query未被下游使用的情况。两层注意力和FFN都应在梯度检查中得到验证。

32×32只增加读取网格密度，不能宣称恢复了S4之前丢失的信息；小目标过小时仍受原特征分辨率限制。首轮不同时增加S16/S32输入。

## 四、SAM 究竟监督什么

使用既有离线、通过质量筛选的每实例 SAM 掩码。只对已匹配正候选、有效实例、进入top64且ROI内有效的轮廓施加辅助监督。

1. 将教师掩码按同一个预测ROI采样为32×32软占据图m。
2. 形成边界带 e=maxpool3(m)−minpool3(m)，裁至非负。
3. 在ROI坐标u,v∈[-1,1]上构造四个软方向权重：L=exp(-4u)，R=exp(4u)，T=exp(-4v)，B=exp(4v)。
4. 各方向教师分布 T_d(p) 与 e(p)×方向权重成正比，在有效网格位置归一化。平滑epsilon=1e-4，归一化用float32。
5. 用 KL(T_d || A_d) 监督末层四边空间注意力。这里的4是固定的首轮超参数，不代表最优值。

这些是“朝向某一侧的轮廓证据”，不是四条真实框边的标签；不宣称注意力峰值就是框边。最终几何位置由GT框监督。

若教师被拒绝、ROI未覆盖足够轮廓或轮廓触到ROI外缘，跳过形状项，仍保留检测框监督。初始规则：边界总mass≥1；边界落在网格最外圈的mass占比≤5%。记录通过率，不静默放宽规则；多实例数据须忽略被拒绝邻近目标区域。首轮Anti-UAV单目标，仍应显式验证实例对应关系。

教师掩码只进入criterion，不能输入学生forward、候选选择、推理坐标计算或门控。无教师的图像仍能正常训练框回归。

## 五、框参数化与稳定性

原框xyxy=(l,t,r,b)，w=r-l，h=b-t。输出四个a，定义：

```text
l' = l + 0.45*w*tanh(aL)
r' = r + 0.45*w*tanh(aR)
t' = t + 0.45*h*tanh(aT)
b' = b + 0.45*h*tanh(aB)
```

只要原框宽高为正，未裁剪的精修框宽高至少为原框的0.1倍，不会左右或上下翻转。四边可分别向内或向外移动。最终MLP末层权重和偏置初始化为零，初始精修框严格等于原框；不额外叠加零初始化门，避免双重零导致学习关闭。

首轮不对框额外裁剪或增加NMS，遵循现有后处理坐标协议。原框宽高异常≤1e-6的候选直接不精修并记录。采样ROI停止坐标梯度；首轮原框和基础特征全部detach/冻结。

0.45是实验范围，不是证明安全或最优。记录GT所需四边修正超出范围的比例、tanh绝对值>0.95比例。若大量候选超范围，应判定局部精修假设或范围不适用，而不是无休止提高损失。

## 六、训练接口：避免与 D-FINE 原生框损失冲突

已核对dfine.py与dfine_criterion.py。旧SQER2保存base_pred_boxes但不修改pred_boxes；criterion还有pred_corners/ref_points等分布回归路径。不能只覆盖pred_boxes便让全部旧损失继续计算。

建议新增：sbr_base_boxes、sbr_refined_boxes、sbr_query_indices、sbr_attention、sbr_roi_grid。

- 训练forward中的pred_boxes仍为原生框，原有匹配、FGL/DDF及其他旧损失保持原语义。
- 新框损失独立读取sbr_refined_boxes，沿用原检测输出的一对一Hungarian匹配，只取进入top64的正候选；不重匹配，不把未选GT偷偷补入top64。
- eval将精修框作为最终pred_boxes，同时保留sbr_base_boxes用于诊断；类别logit完全不变。
- 验证训练/eval两条路径的精修框数值一致，不能误把训练输出原框拿去统计新模块AP。

首轮只训练新分支，其余所有旧模块eval且冻结，包括旧SQER投影/分类头、C、M、SGC关联骨干及decoder。这样原检测输出恒定，明确检验“已有特征能否支持形状指导的框精修”。这不等于完整联合训练效果；若成功再讨论联合微调。

损失（初始建议，实施前记录为固定配置）：

```text
L = 5 * mean_positive L1(normalized_cxcywh_refined, GT)
  + 2 * mean_positive (1-GIoU(refined, GT))
  + 0.05 * mean_valid_shape KL(T || A)
  + 0.1 * mean_selected_unmatched |tanh(a)|
```

最后一项要求未匹配候选尽量保持原框，防止只训练正候选却任意改变背景候选。各项分别按各自有效候选归一化；空集合返回与计算图相连的零值，无NaN。没有GT的图像也参与未匹配稳定项。首步框头为零时上游框回归梯度可能为零是正常的；第二次更新后必须验证恢复，形状监督可从首步传播。

## 七、最小对照：两组训练，一个原模型基线

所有基础模型统一使用已审核R2 full EMA：
`outputs/M_LAYOUT_RECOVERY_20E_TESTDEV/R2_OTE2_LAYOUT/seed0/best_stg1.pth`，SHA256 `d7fc60568887e12ba66fbe5b474d09be5cfcc5dd4fe14bc102556b5e5b5aa952`。

| 组别 | 新精修结构 | 新四边SAM监督 | 用途 |
|---|---|---|---|
| R0 | 无/旁路 | 无新增 | 同脚本复评旧基线，不训练 |
| R1 | 有 | 权重0 | 衡量新增定位结构本身 |
| R2 | 与R1完全相同 | 权重0.05 | 衡量新增轮廓监督的额外贡献 |

**R1不是“完全没有SAM”的模型！** 三组均继承旧SGC2/SQER2。R2−R1只能说明新增定位分支的SAM监督贡献，不能归为整个系统SAM有无的因果对照。R2若胜出但需要论证精细轮廓优于粗几何，再增加同结构BOX边界监督组；首轮不提前扩展实验矩阵。

建议首轮30epoch、AdamW lr=1e-4、weight_decay=1e-4、clip_grad_norm=1、1epoch线性warmup后cosine降至1e-6；batch16，若OOM固定两组均为8，梯度累积2保持有效batch16。种子0，新模块初始化state保存一份供两组复用；同一数据顺序，无随机增强，保持512×640。冻结基座后这种训练是明确的定位读取探针，不是从头训练结果。

采用3200训练/1820既有test-dev，明确该1820已用于开发，不能包装为未见独立测试。无多种子。每组以最佳总AP对应checkpoint汇报全指标，不拼接不同epoch指标；保留曲线，不用末几轮取代最佳结果。

## 八、验收与停止条件

开训前必须通过：

1. 新末层零初始化/旁路时，300个框和类别logit对旧模型数值一致；同评估器复评R0。
2. 所有未选候选完全不变；所有分类logit完全不变。
3. teacher缺失仍能推理；用不同teacher输入不改变eval输出。
4. loss分别对新查询/attention/FFN/box头的梯度检查，基座无梯度；两组冻结参数摘要相同。
5. ROI图像边缘、极小框、空GT、无有效掩码、batch>1、不同输入尺寸均无NaN/串候选。
6. 同一Hungarian匹配下，原/精修IoU和像素四边误差成对输出。

主要读数：COCO AP/AP50/AP75/APS/APM及全部AR，原到精修的逐GT IoU变化、IoU≥0.75净增减、四边误差、负候选变化、超范围比例、教师通过率。框分支不修改分数，因此获得的AP差异可定位到框变化，但仍不能跳过R1/R2比较来声称SAM是原因。

- R1和R2都不优于R0：不支持当前精修结构；先查可用定位信息和修正范围，不加深网络碰运气。
- 两者均优于R0但R2不优于R1：结构有用，新增SAM监督未获证实。
- R2优于R1且定位诊断方向一致：支持形状指导对定位有帮助；单次实验不等于统计显著或原创性已确立。
- AP提高但APS下降：不能宣称小目标普遍改善；分别报告。
- 形状KL下降但IoU不改善：更像教师不等于检测更好，优先检查教师轮廓与GT框规范差异。

## 九、执行文件建议

新增 `src/zoo/dfine/sam_boundary_refiner.py`；在dfine.py增加可选分支，在criterion新增独立损失，增加R1/R2两份配置及同权重旁路诊断脚本。旧sam_query_evidence_reader.py只做必要的共享memory接口重构，并以严格前向回归测试保护旧数值。不要改变旧类默认返回行为或历史配置。

可把旧fusion输出临时缓存给新分支，forward结束清空，禁止跨batch缓存持有图。基座冻结期间共享的是同一张feature map；新分支不反向更新旧SQER投影。未来联合训练必须重新说明共享梯度影响，不能套用首轮隔离结论。

## 十、参考思想与叙事边界

- Grid R-CNN，CVPR2019：使用网格引导定位，而非仅靠整体特征回归框。支持局部空间证据有研究先例，不代表本设计复现其结构。官方论文：https://openaccess.thecvf.com/content_CVPR_2019/html/Lu_Grid_R-CNN_CVPR_2019_paper.html
- PointRend，CVPR2020：通过点式特征读取处理精细分割边界。启发保留局部空间信息，不证明增加ROI采样密度能恢复不存在的细节。官方论文：https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html

暂定机制表述：“利用离线分割轮廓指导四个方向的局部证据读取，以检测框监督将形状知识转化为定位修正。”
