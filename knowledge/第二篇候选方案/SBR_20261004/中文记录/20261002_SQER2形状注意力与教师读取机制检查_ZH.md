# SQER2 形状注意力与教师读取机制检查

日期：2026-10-02。

## 1. 要回答的问题

用户担心 SAM 只影响三个角色向量，实际注意力可能与 SAM 形状关系很弱。本轮不修改模型、不训练新权重，只检查：

1. 已训练的三张注意力分布是否接近 SAM 提供的前景、边界、邻近背景分布？
2. 保持 RGB 局部特征和分类修正头不变，用教师分布代替学生注意力，读取结果如何变化？

第二项只是固定权重的条件性干预，不是新模型，更不是正式验证集检测性能。

## 2. 实际实现与核验

源码 `D-FINE/src/zoo/dfine/sam_query_evidence_reader.py`：SAM 掩码在候选 ROI 中采样，再形成三个归一化空间分布。训练损失直接比较这些分布和学生注意力，不仅监督三个可学习角色向量。

学生最后一层四头注意力取均值，得到每个候选的 3×256 分布。该分布乘以原始 ROI memory（256×64），得到三个 64 维证据；前景减背景、边界减背景拼成 128 维证据，经过既有评分头和有界门控，修正原始分类 logit。不改变预测框。

本轮通过临时内存包装强制返回注意力，通过前向钩子读取相同的 ROI memory。正式模型文件没有改动。重算学生分支的 logit 增量与原始前向结果逐目标比较，全部通过绝对误差不超过 0.003 的检查。使用 EMA 权重，严格加载，无缺失参数；模型 eval、inference_mode，无优化器。

## 4. 注意力是否学会 SAM 的区域分布

KL 的方向统一为“教师 SAM 分布 → 被比较的读取分布”，越小越接近。

| 角色 | 学生注意力 KL | 均匀注意力 KL |
|---|---:|---:|
| 前景 | 0.2512 | 1.9784 |
| 边界 | 0.2963 | 1.3808 |
| 邻近背景 | 0.6662 | 1.6534 |

三个角色的学生分布平均总变差距离（0 相同，1 完全分离）：前景/边界 0.4834，前景/背景 0.9514，边界/背景 0.7867。

判断：至少在已见样本上，注意力确实学到了 SAM 区域监督，且角色没有坍缩为同一张图。边界角色也并非只有名字。这反驳“只能影响三个角色向量、与空间权重没有直接关系”的理解。

限制：没有训练前或无形状监督同结构检查点的配对注意力比较，不能把所有空间选择能力都因果归于 SAM；没有比较中心先验等更强基线，也不能据此声称已经学到 SAM 独有的精细轮廓。不同教师作为 KL 第一项时熵不同，不能直接用两种方向不同的 KL 大小来排名老师优劣。

## 5. 保留评分头，替换区域读取分布

以下仅是 240 个已匹配正候选的 logit 增量均值，不是 AP，不是概率百分点。

| 读取分布 | 分类 logit 增量均值 |
|---|---:|
| 原学生注意力 | -0.00710 |
| SAM 教师区域 | -0.00862 |
| GT 框派生区域 | -0.05510 |
| 三角色均匀读取 | 0.00000 |
| SAM 前景/背景角色互换 | +0.01336 |

教师 SAM 读取的增量超过学生读取的比例为 48.75%，没有一致抬高正候选分数。均匀读取三个区域得到相同证据，因此相减为零，这是结构预期的校验。

**不能根据均值负数断言模块失败，也不能根据角色互换均值为正断言交换角色更好。** 检测依赖正负候选的相对排序和框质量；这里只看已匹配正候选，没有替换全部候选，也没有评估误检。已有头是在学生注意力分布下训练，教师干预还可能造成分布变化。

本轮只能得出：没有发现“只要把注意力换得更像 SAM，既有头便一致提高正候选分数”的简单现象。不能据此证明 SAM 无用，也不能证明教师读取提高 AP。

## 6. 下一步的判断

目前不支持为增加 SAM 参与感而直接堆叠卷积或提高监督权重。先前怀疑的“学生根本没学到教师区域”不是本轮数据支持的主要解释。

更值得检查的是：**形状指导得到的证据，是否对目标/背景判别以及定位质量相关的候选排序有帮助。** 当前分类头只有全局检测损失，并没有保证前景/背景差异或边界信息以预期方式改变评分。

下一步最小检查应扩展到全部被选候选：记录原始与 SQER 修正后的分数、各候选与 GT 的 IoU、前景/边界/背景证据和修改量；分别分析可靠目标候选、低定位质量候选、纯背景候选。保留学生正常推理作为正式结果，教师读取继续独立标注为诊断。必要时再增加未见样本掩码并检查注意力泛化。

只有在上述分析发现证据使用环节确有瓶颈后，才考虑让区域证据学习显式服务于候选质量或目标/近背景区分。不预先承诺新损失有效，不把另一个区域对齐损失误称为完全不同机制。
