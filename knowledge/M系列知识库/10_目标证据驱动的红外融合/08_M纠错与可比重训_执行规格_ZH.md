# M 纠错与可比重训：执行规格

日期：2026-09-26。状态：分析设计完成，**尚未修改生产模型、尚未启动训练**。配套依据为 `07_M模块深度复核_实现错误与机制裁决_ZH.md`。本文供下一执行阶段使用；本轮无需执行者重新设计融合模块。

## 1. 优先目标和训练范围

完成正确 IR 源下的两组短程比较：

- R1：C-GQ1 + SGC2-SAM + SQER2-SAM + 旧 M-SD2.2 半强度。
- R2：同一 C/S 底座 + M-OTE2-L，仅修正 E2 的错误 BCHW 重排。

两组都从 COCO 通用权重提供的任务起点训练，正确 IR 源冻结；新增任务参数按固定随机初始化共同生成。不要载入成熟 A1、A5、E1 或 E2 的 RGB 检测权重作为起点。20 轮总预算，物理 batch8、累积4，seed0，Windows `hello_word`。不延长轮数，不增加随机种子。

本轮使用原始 3200 训练图与 1820 testdev，既有 SAM 缓存不变。不是30万规模训练，不进行新数据下载。

## 2. 修复范围：一处正确性问题

文件：`D-FINE/src/zoo/dfine/target_evidence_thermal_fusion.py`。

正确路径：

```python
# generated_response already returns BCHW.
raw_update = full_response - null_response
```

旧路径错误地执行了 `.transpose(1, 2).reshape(...)`。

为避免旧 E2 checkpoint 在当前源码下被悄悄重新定义，增加一个**不增加参数**的布局版本开关，例如 `mote_layout_fix`，并在最终解析配置/报告中记录：

- 旧 E2 配置显式为 False，保持历史布局，仅供复现；
- 新 R2 配置显式为 True；
- 构造参数传至 `TargetEvidenceThermalFusion`，权重键和形状不变；
- 旧 E2 诊断不能因默认值变化而自动走新布局。

执行者可以选择等价的布局枚举命名，但必须同时满足历史可复现与新路径明确启用，不得用 checkpoint epoch 等隐式条件决定行为。此开关是历史兼容，不是需要训练或调参的模块。

首轮保持其它 E2 机制：4 个 IR 预测候选、S8/S16 单格 gather、目标/背景/空槽读取、原门控顺序、3%限幅、0.5最终强度、IR目标性损失0.1、仅 S16 写入。局部池化、门移位、关系监督和 RGB 保护损失都属于后续独立修改，不纳入 R2。

## 3. 初始化：保留任务起点，允许任务特有参数随机初始化

历史通用源：`[项目根目录]/weights/m_sd2_joint_coco_thermal_identity_init.pth`。其中 RGB 部分来自 COCO，包含可兼容的 backbone/encoder/decoder 张量；不含当前 RGB C-GQ1 参数及单类别 score head。这是正常情况，**不能为补齐缺失键而换用已训练好的 A1**。

正确 IR 源：`[项目根目录]/outputs/M_IR_RAW_VERIFIED_GQ1_30E_TESTDEV/seed0/best_stg1.pth`，取 `ema.module`；SHA256 为 `9416a3c4734e7b15e86889ae6bc3161f10051efc1717c5800b3bb10bc234f0a0`。

建议生成完整、独立的新任务初始化，而不是覆盖历史文件：

1. 按 seed0 构造与 R1/R2 公共部分一致的 C/S 模型，捕获它的初始状态。
2. 只覆盖历史通用源中 RGB 侧可兼容键；对缺失的 C、单类头、SQER 等任务参数保留一致的构造值，列出完整允许清单。
3. 从正确 IR 源映射 `backbone.*→thermal_backbone.*`、`encoder.*→thermal_encoder.*`，要求564个对应张量全部映射。不得沿用通用源内的旧 IR 张量。
4. R1/R2 共用的全部 RGB、C、S、IR 参数及缓冲区逐键一致，保存完整 SHA 与来源。M 特有参数各自按固定 seed 构造，零输出初始化。
5. 禁止加载成熟检测优化器状态；两个新任务的优化器都从零开始。第一轮模型不是已经训练好的 53.x 检测器，初始 AP 很低是预期。
6. 初始化器必须区分“允许的新参数”和“意外漏载”，而不是采用缺键就换源的处理方式。若出现模板之外缺键、IR映射不全，停止并报告。

加载后的第一个真实 batch，R1/R2 的 RGB logits/boxes 应在 M 输出为零、SQER旁路时一致。初始化权重文件不保存任何训练 GT、SAM输出或测试预测。

## 4. 训练协议

参考 A5 的 `sqer2_common_warmup_b8a4_2e.yml` 与 `sqer2_sam_b8a4_20e.yml` 解析结果，不直接从已有两轮 warmup checkpoint 续训，因为它已包含旧 IR 来源下的优化轨迹。

| 项目 | 设置 |
|---|---|
| RGB骨干学习率 | 1e-4 |
| 编码器、解码器、新 M、SQER 学习率 | 2e-4，沿用相应规范化/偏置免衰减分组 |
| 优化器 | AdamW，foreach=False，betas=(0.9,0.999)，weight_decay=1e-4 |
| warmup | 原 LinearWarmup，500步；按原代码解释其步数 |
| 主调度器 | 原 MultiStepLR，milestones=[500]，gamma=0.1；本轮不另加后期衰减 |
| EMA | 原 decay=0.9999、warmups=1000、start=0 |
| 图像与增强 | 原512×640、无随机裁剪的 RGB-T 配方；相同数据流 |
| IR提取 | 冻结 backbone/encoder 与 BN，forward chunk=2 |
| SQER | epoch0–1旁路、shape loss=0；epoch2–19开启、shape loss=0.05 |
| SGC2 | 保留 SAM 分组监督，原权重10；epoch9–14衰减 |
| 正确IR框 | `data/antiuav6k_ir_raw_verified/{train,test}/labels` |
| SAM缓存 | 原 `reports/104_sam3_role_control/masks_train` |
| 精度与批量 | AMP；batch8×累积4，不在本轮改变物理batch |

两组分别训练自己的前两轮，再恢复自己的 checkpoint 到总20轮。恢复模型、优化器、LR调度器、warmup、EMA、scaler等状态；前两轮已计入总预算。

R1/R2 模块参数量不同，构造阶段会消费不同数量随机数。共同初始化生成后，应让正式数据排序/增强的随机状态一致，并记录前若干 batch 的图像 ID 与增强签名。遵循 A5 分段启动的随机状态处理；若需要引入一个更严格的重置方案，两组统一执行，并如实称“匹配的重建协议”，不承诺逐bit复现历史 A5。

每组创建新配置、输出目录与源码快照，建议总目录 `outputs/M_LAYOUT_RECOVERY_20E_TESTDEV/{R1_SD22,R2_OTE2_LAYOUT}/seed0`，报告目录同名 `reports/M_LAYOUT_RECOVERY_20E_TESTDEV`。不得覆盖 E0/E1/E2 或 A5。

## 5. 必须完成的预检

1. **非零布局测试。** 零初始化恒等检查之外，用唯一索引/单点脉冲验证补偿的通道和RGB位置不被打散；非零输出头下，固定IR、平移RGB特征，补偿应同步平移。现有审计脚本给出原错误相对误差1.4587、修正后约5.36e-7。
2. **历史复现。** 新开关的旧模式必须与原 E2 源码同权重输出一致；新模式与直接 `full_response-null_response` 一致。这个检查使用随机非零输出，不能只测零起点。
3. **公共起点。** 逐键一致、IR来源哈希正确、C/单类头/SQER允许缺键清单完整；R1/R2零残差起点预测一致。
4. **真实训练流。** 真实 batch 的 RGB/IR框变换与SAM掩码对应；训练期IR框为归一化CXCYWH；验证前向不接收任何GT；完整检测损失有限。
5. **两步梯度与冻结。** 初始输出层能打开，后续读取器获得有限梯度；模型与EMA的IR冻结张量/BN不漂移；梯度累积更新数正确。
6. **损失路径分开记录。** 目标性损失只训练IR目标头是预期；检测损失必须能到达token、query/key、生成器。不要把“至少一个M参数有梯度”写成全部路径已验证。

上述属于正确性预检，不需增加另一组完整训练。

## 6. 训练结束后的最少验证

两组均报告最佳 EMA 的完整12项COCO指标、最佳epoch、末段曲线、权重SHA。按最佳 AP 选型；APS/AP75/APM用于解释代价，末段均值只用于诊断。

对两组最佳权重分别评估：

- 正常IR；
- 同权重关闭M；
- 若正常优于关闭，追加训练集固定平均IR证据控制，检验收益能否由固定条件代替。

R1可复用本轮 `prototype` 思路；R2固定条件控制须冻结所有来自IR的候选内容、背景内容及候选分数，不得只固定token而继续让每图候选置信度输入门控，然后声称“完全移除了IR变化”。固定值只由训练图计算，testdev不用于选阈值。

R2另记录：候选召回、前景/近背景的目标token注意力质量、归一化熵、生成补偿与最终补偿RMS、门值分布。使用RGB/IR GT做这些离线统计可以，但不要传入部署推理。全图64例可以作定位检查，正式机制结论需要记录覆盖范围，不能冒充全1820图统计。

## 7. 结果如何决定后续

- **R2超过R1且有同权重内容收益：** 保留R2，优先补同任务起点的C+S无M训练控制，建立论文所需的总体贡献；暂不再复杂化。
- **R1有效，R2弱：** 保留R1作为可用版本。若R2读取仍近均匀、有效IR候选经常被当背景，下一单项修改为07第8节的目标—背景关系监督。
- **R2有内容收益但总AP未超过R1：** 看损失发生于哪些尺寸和IoU范围；仅在读出诊断指向明确问题时进入关系监督，不为凑复杂度同时改四项。
- **两者都没有正向内容收益：** 转查新IR表示与检测接口的适配。旧A5有效不等于新IR源一定更适合当前M；IR单模态AP和融合价值不是同一指标。此时不自动续训、不加大幅度、不重新铺门控搜索。

两组实验没有同起点无M训练组，因此只能先裁决候选替换与即时IR作用，不能直接写“相对无M训练提高X点”。这项限制必须保留在结果文档里。

## 8. 关于条件性关系监督的执行边界

07已解释其机制，但首轮R1/R2不执行。若数据支持启动，应另做具体实现小规格，至少明确：SAM软前景/近背景在S16的有效质量、候选真目标标签、前景/背景均衡、无候选/单侧存在样本处理、损失权重及监控。

不得直接复用SGC的“至少2个纯前景格”标准到S16，否则容易再次排除最小目标。不得用GT挑候选、用测试SAM作为推理门、把不同drone实例一律当跨图负样本，或把注意力集中当成最终AP成功。
