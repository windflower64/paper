# A5 最佳权重选型与两级 SAM 形状指导的统一叙事

日期：2026-09-25。依据：同协议 A0–A5 单种子、20 epoch、3,200 张训练子集、1,820 张 testdev 的贡献分离实验。原始执行过程见 `20260924_C_M_SAM_SQER2贡献分离_执行记录_ZH.md`，配置、逐 epoch 日志和旁路评估 JSON 随本次 Git 归档。

## 先明确选型口径

模型选型使用**各组最佳权重在同一 testdev 上的指标**，而不是末轮或末五轮均值。后者只用来提示曲线波动。六组均为 seed 0；本轮不能据此宣称统计显著或跨数据集泛化。A0/A1 是 RGB-only，A2–A5 是 RGB-T；因此 A5 相对 A0 的总差不能全部归因于 SAM。

## 两个 SAM 机制实际做了什么

- **SGC2：表征层。** 训练时用 SAM 掩码在 RGB S8 特征上划分目标内部与邻近背景，施加分组对比约束，促使特征更易区分两者。A5 中它是 S8 训练监督，推理时不需要掩码，也没有新增 SGC2 推理分支。它不是直接生成或补回一张 S16 边缘图。
- **SQER2：决策层。** 在检测 query 的局部 S4/S8 证据上区分目标内部、过渡边界、邻近背景；训练时由 SAM 形状指导注意力分布，并学习一个有界的分类 logit 修正。它不直接修改预测框或 S16 特征。推理保留读出支路，但不使用 SAM 掩码。

二者共享一个问题：**如何把 SAM 的形状知识转化为检测器可用的“目标—边界—近背景”辨别能力**。可统一命名为“分层形状引导检测机制”（暂用工作名，不代表已确立论文命名），下设特征层分组约束与 query 层局部证据读取。论文主图画成一个训练框架、两个作用点，而非两个互不相关的创新模块；方法小节保留两段实现说明，消融仍分别报告 A2/A3/A4/A5。这样统一的是研究假设和信息流，不伪称它们在代码里是一个连续算子。

## 证据边界与审稿风险

按最佳权重看，A3、A4、A5 相对 A2 的 AP 分别为 +0.368、+0.140、+0.863；A5 是最好的模型。但各组最佳 epoch 不同，这些峰值差**不能单独证明两个机制协同**。对齐 epoch 2–19 后，A4−A2 的 AP 均值/末五轮差为 +0.059/+0.198，A5−A3 为 -0.142/-0.177；SQER2 对后段 AP 的稳定贡献未获支持。SQER2 对召回有一定正向趋势，且它对训练轨迹的影响可能大于推理即时读出：同一 A4/A5 最佳权重正常与旁路读取的 AP 差仅 -0.0108/-0.0067 点。不能把 A5 的峰值全部归功于 SQER2，更不能宣称已经证实“直接修复下采样丢失的边缘”。

审稿人可能质疑模块堆积，如果仅把 SGC2、SQER2 写成两个并列“涨点技巧”。降低此风险的关键不是改类名，而是：用同一个检测问题解释两个作用层级，明确 SAM 仅在训练时提供形状教师信息，给出四格消融，同时如实报告 APS 和旁路结果。当前证据足以把 A5 作为最佳候选并形成统一方法叙事；不足以把双层协同、小目标边缘恢复或泛化提升写成已证实结论。

## 代码组织建议

**暂不为论文叙事强行合并成单个 `nn.Module`。** 现有 SGC2 是作用在 S8 的训练损失，SQER2 则含 query 读出和形状损失，生命周期、输入输出不同。物理合并会影响参数命名、权重兼容与消融开关，使已经验证的 A5 不再是原样模型。若后续为维护性做统一接口，可只增加无行为变化的上层组织/命名，并用同权重输出一致性检查；论文中的“一个方法、两个环节”不依赖代码物理合并。
